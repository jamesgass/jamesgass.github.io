Writing Mathematics

With MathJax installed in the document head, you can write LaTeX directly into your HTML.

  • For inline equations, use the \( ... \) delimiters. For example, \( e^{i\pi} + 1 = 0 \).
  • For block display equations, use the \[ ... \] delimiters:
\[ \zeta(s) = \sum_{n=1}^{\infty} \frac{1}{n^s} \]

How to expand

To create new pages, duplicate this file, rename it (e.g., coursework.html), and change the content inside the <main> tags while leaving the <nav> menu exactly the same.
